01 · Introduction

What is a Decision Tree?

A Decision Tree is a supervised machine learning algorithm used for classification and regression. It splits data into smaller groups by asking questions about input features. The result is a tree-like structure that can be followed to make a prediction.

🎯

Objective

Learn decision rules from data to predict a category or a numerical value.

🌿

Learning Type

Supervised learning: training examples contain known target values.

🏡

Simple Example

Use features such as weather and temperature to help predict whether someone will play outside.

02 · Tree Structure

Meet the parts of a tree

🌱

Root Node

The first node, where the tree begins and the first split is made.

🔀

Decision Node

A node that checks a feature or condition and sends data along a branch.

🍃

Leaf Node

A final node that gives a class prediction or a numerical prediction.

03 · Mathematical Concept

How does a tree choose a split?

For classification, a Decision Tree may use Gini Impurity or Entropy to measure how mixed the classes are in a node. A useful split reduces impurity.

Gini = 1 − Σ pᵢ² pᵢ = proportion of observations belonging to class i

Gini Impurity

A value of 0 means the node contains only one class. Larger values indicate more class mixing.

Entropy

Another measure of class uncertainty. Information gain compares entropy before and after a split.

Regression Trees

For numerical targets, splits may be chosen to reduce squared error or another suitable loss.

04 · How It Works

From training data to prediction

Step 1 — Collect data

Gather examples with input features and known outcomes.

Step 2 — Select a feature and split

The algorithm evaluates candidate splits using a criterion such as Gini Impurity.

Step 3 — Grow the tree

It repeats splitting on the resulting groups while the stopping rules allow it.

Step 4 — Make a prediction

A new observation follows the conditions from the root to a leaf.

Step 5 — Evaluate and control complexity

Test on unseen data. Limit depth or prune the tree when needed to reduce overfitting.

07 · Evaluation

Advantages and limitations

💚 Advantages

  • Easy to visualise and explain.
  • Can model non-linear relationships.
  • Can handle numerical and categorical features with appropriate preprocessing.

💜 Limitations

  • Deep trees can overfit training data.
  • Small changes in data can produce a different tree.
  • A single tree may be less accurate than some ensemble models.

🔎 Remember

Use validation or test data and control tree complexity to help assess whether the model generalises to new examples.

09 · Conclusion

What have we learned?

A Decision Tree is a supervised machine learning algorithm that predicts outcomes by applying a sequence of learned conditions. Its root, decision nodes, branches and leaves make the prediction process relatively easy to follow.

In this blog, we explored how trees work, how Gini Impurity can help select classification splits, and how Decision Trees are used in different fields. We also learned that a tree that is too complex can overfit the training data.

Key takeaway: Decision Trees turn patterns in data into a series of understandable rules. Good evaluation and complexity control help improve their usefulness on unseen data.
